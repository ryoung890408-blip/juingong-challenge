# 7일 주인공(主人空) 챌린지 — 설치형 웹앱(PWA)

대학생 7일 주인공(主人空) 챌린지를 휴대폰 홈 화면에 설치해서 쓰는 웹앱이에요.
한 번 열어 두면 인터넷이 없어도 음성 안내와 배경음까지 그대로 동작해요.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.webmanifest` | 앱 이름·아이콘·색상 설정 |
| `sw.js` | 오프라인용 서비스 워커 |
| `icons/` | 앱 아이콘 (192, 512, 마스커블 512, 애플 180) |
| `univ_voice.mp3`, `univ_bgm.mp3` | 관법 안내 음성, 배경음 |

> 앱 설치는 **https 주소**에서만 됩니다(아래 무료 호스팅은 모두 https). 파일을 그냥 더블클릭해서 열면 설치/오프라인 기능은 빠지고 일반 웹페이지로만 동작해요.

## 무료로 올리기

### 방법 1. Netlify Drop (가장 쉬움, 드래그 앤 드롭)
1. 이 폴더(또는 zip을 푼 폴더) 안의 파일 전체를 준비해요. `index.html`이 폴더 맨 위에 있어야 해요.
2. 브라우저에서 <https://app.netlify.com/drop> 접속
3. 폴더를 화면에 끌어다 놓으면 몇 초 안에 `https://○○○.netlify.app` 주소가 생겨요.
4. 그 주소를 학생들에게 공유하면 끝! (로그인하면 주소를 원하는 이름으로 바꿀 수 있어요.)

### 방법 2. GitHub Pages
1. GitHub에서 새 저장소(Public)를 만들고, 이 폴더의 파일을 **저장소 맨 위(루트)** 에 올려요.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장해요.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 열려요. 하위 경로에서도 동작하도록 모든 경로를 상대 경로로 만들어 두었어요.

## 학생 설치 방법

### 안드로이드 (크롬)
1. 크롬으로 공유받은 주소를 열어요.
2. 화면 위에 뜨는 **「홈 화면에 추가」** 버튼을 누르고 **설치**를 눌러요.
   (버튼이 안 보이면 크롬 오른쪽 위 **⋮ → 앱 설치(홈 화면에 추가)**)
3. 홈 화면의 **주인공 챌린지** 아이콘으로 실행해요.

### 아이폰 (사파리)
1. 반드시 **사파리**로 주소를 열어요. (카카오톡·인스타 안 브라우저에서는 설치가 안 돼요. 오른쪽 아래 **⋯ → Safari로 열기**)
2. 아래쪽 **공유 버튼(□↑)** 을 눌러요.
3. **홈 화면에 추가**를 누르고 오른쪽 위 **추가**를 눌러요.
4. 홈 화면의 **주인공 챌린지** 아이콘으로 실행해요.

## 알아 두세요
- **출석 기록은 각자 휴대폰에만 저장돼요**(localStorage). 폰을 바꾸거나 브라우저 데이터를 지우면 사라지고, 기기끼리 동기화되지 않아요. 제출은 앱 안의 「텍스트 복사」「.txt 저장」 기능으로 하게 돼요.
- **아이폰은 홈 화면 앱과 사파리가 기록을 따로 저장해요.** 설치 후에는 홈 화면 아이콘으로만 쓰도록 안내해 주세요. 사파리에서 쓰던 기록은 설치한 앱으로 옮겨지지 않을 수 있어요.
- **음성·배경음 자동 재생**: 아이폰은 화면을 직접 누른 뒤에만 소리가 나요. 이 앱은 버튼을 누른 뒤 3단계로 넘어가므로 대부분 재생되지만, 무음 모드(벨소리 스위치)이거나 저전력 모드이면 소리가 안 날 수 있어요. 소리가 안 나도 자막은 시간에 맞춰 넘어가요.
- **글꼴(Pretendard)** 은 인터넷에서 불러와요. 한 번 열면 저장되어 이후 오프라인에서도 쓰이고, 처음부터 오프라인이면 기본 한글 글꼴로 보여요.
- **앱을 수정해서 다시 올릴 때**는 `sw.js` 맨 위의 `const VERSION = 'v1';`을 `'v2'`처럼 올려야 학생들 폰에 새 버전이 반영돼요.
